# Authored cooperative patrol extraction

This opt-in challenge joins the accepted gate, designated patrol target, verified
four-person team, inventory and cooperative extraction in the same guided app.
It is authored test geometry, not original Training43 machinery or a complete
original level. Load the ready-to-play local Training43 test, then choose **Start
authored patrol extraction challenge** under **Choose and start a test**. Setup
rehashes the selected team's OCS sources and resets all challenge state, paused.

Start mission. Slot 1 starts facing the gate panel: press **1**, then **C** to open.
**F** fires the fixed slot-1 loadout at the designated target; allow its existing
cooldown between shots. **T** toggles deliberate misses. This retains the existing
nonspatial F/T and source gun arithmetic; there is no range, aim, line of sight,
enemy attack or player damage system. Defeating the target stops its patrol and
unlocks the single marked exit at **8,5,1**. The locked exit is an ordinary wall,
labelled as an authored objective lock. The unlocked block uses existing source
block type 3 exit-bump behavior. The map and rendered collision update together.

Use **1–4** to assign WASD to each mercenary; **W/S** forward/back, **A/D** sidestep,
**Q/E** turn, **Esc** pause. Keep the gate open. From the canonical starts, without
turning, these routes finish after target defeat:

| Selected slot | Keys, one movement per letter |
| --- | --- |
| 1 | D, W, W, W, W |
| 2 | A, S, S |
| 3 | W, D, W, D, D, D, D |
| 4 | W, W, D |

Each final command bumps the exit from 7,5; the actor retires at that approach
pose and releases occupancy. All four must extract. Retired actors cannot move,
activate the panel or change equipment; the fixed gun actor cannot fire or change
target after retirement. No new actor death behavior is installed. The objective,
gate, target, lock, run/outcome state and extracted count are visible without raw
JSON. The overhead marker uses L for locked and E for unlocked; an expandable
keyboard walkthrough is adjacent.

The fixed limit is **10 source clock counts, each 601 accepted world ticks**:
6,010 ticks (120.2 seconds at uninterrupted 50 Hz). Pause freezes the clock.
Timeout wins even if the fourth extraction occurs on tick 6,010. Rules are fixed
to cooperative extraction. After win or failure, movement, patrol, firing and
activation stop. **Y** retries after an outcome; the Retry mission button also
works while active. Retry resets world, mission, gate, target, inventory, ammo and
history together, paused. Y ignores repeats, held edges, modifiers and form focus.

## Source-bound recovery

The distinct canonical fixture is `authored-patrol-extraction-v1`. Exact session
v11 retains the v10 field set, using that fixture for `scenario`, `patrol.fixture`
and the authored map source binding. Its fixed geometry/profile is generated by
code. No serialized exit lock, rules, route, geometry, outcome, clock, positions,
health or inventory has authority: all receipts must match complete chronological
replay from canonical starts and freshly verified raw roster/items. Unlocking is
derived solely from replayed target health. Checkpoint schema remains 3.

All prior v1–v10 shapes remain unchanged. Loading a matching v9/v10 practice save
from the challenge restores the canonical navigation arena and clears challenge
mode. Original Training43, ground and selected-fall require their matching mode or
a fresh ready preset/Apply. No old fall or ground history is reinterpreted.

Open/locked, unlocked, partly extracted, won and failed saves restore paused.
Setup, save and inventory work snapshot caller sources, map, indices, world and
history before their first await. Retry, rules changes, source/selection changes,
new Apply and mode changes cancel stale installs. Invalid recovery retains the
complete current state apart from pausing. Full history is retained with the
existing 128-event / 45,000-tick bounds and lossless adjacent waits. Prospective
tick/F/T/item candidates retain the existing UTF-8 limits: outer <24 KiB, nested
checkpoint <16 KiB. Budget refusal never partially installs world/session state.
Terminal histories cannot append events or conceal extra ticks after the outcome.

Public tests use synthetic logical gun rows and an independent exit/clock oracle.
Opt-in private tests rehash actual OCS inputs and cover canonical replay, mutation
races, inventory, all extraction receipts and failed recovery. Production browser
tests finish twice through actual keyboard controls, exercise lock/retirement,
terminal freeze, Y Retry and partial/won/failed restore, malformed receipts,
deadline ties and asynchronous cancellation. Near-deadline browser fixtures are
produced by accepted source-bound event replay, then the last ticks/exit execute
in the browser; they do not count as the fresh keyboard full-win evidence.

Independent final-head HIGH review, CI and completed automatic review remain
coordinator release gates. Training43 and functional-test-bed acceptance remain
open. Original AI/combat, moving doors/pads/lifts, wet outcomes, general item use,
original lifecycle, campaign, artwork/audio and physical controller parity are
outside this challenge.
