# Runtime map selector producer boundary

The original selector producer is now bound to two record-copy paths in the
pinned executable and retained source. The action-game path indexes the runtime
Locations buffer using a one-based action selection, then copies a complete
location record into the current-location record. The campaign path copies a
validated location pointer after the choice/completion decision. In both paths,
the map selector inherits the corresponding byte from that record; it is not
computed from the editor fixture's map label.

The private proof checks the compiled dispatcher, index arithmetic, copy counts,
byte-copy loops, destination and subsequent loader selector read against the
source declarations. A complete symbolic projection gives every copied byte one
input-record origin. It establishes the copy relationship without choosing a
record, producing runtime bytes or claiming original CPU execution.

Initial campaign selection is a separate preceding decision: it uses the stored
random state, runtime record count and start-type records. Later campaign choice
also needs the actual validated pointer and choice/completion state. The retained
runtime-table loader supplies the Locations buffer before those decisions.
These are conditional source requirements, not evidence of an actual invocation.

The first unsupported input at the compiled producer dispatcher is the actual
action/campaign mode flag. Its accepted source value and origin are both unknown.
The accepted runtime Locations buffer, action selection and relevant caller
state also lack authority. Archived decoded tables remain diagnostic inputs;
their presence does not bind a table to this runtime load or identify a selection.
The editor/runtime Locations revision mismatch still blocks graph substitution.

The batch stops at that source/caller gate. It executes no original instruction,
load, decompression or fall continuation and installs no output. The selector and
four blocked operand origins remain unknown; accepted memory, source masks and
the existing open fall frame are preserved. All inherited evidence is rehashed,
and fresh reproduction plus preserving refusal checks remain local and ignored.

version one and browser behavior are unchanged. Fall, damage/death/control,
occupancy, wet traversal, pads/corpses and source-bound atomic paused recovery
remain gated; physical controller, TV and full-level acceptance remain separate.
