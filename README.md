# Hired Guns Revival

Browser revival in progress. Four synchronized 3D views support independent local navigation and a bounded extraction mission flow. One complete original level is the birthday fallback; full campaign is a stretch target. No complete faithful original level is validated yet.

**Extraction missions:** choose **Extraction drill** for a newly authored timed test scenario. Move each mercenary into the glowing exit; cooperative mode finishes only when all four escape. Escaped mercenaries stop occupying the grid. Use **Retry mission** after success or timeout, or restore a checkpoint. **Mission rules** also offers the original training's first-exit race and navigation-only exploration; changing rules restarts the mission.

**Dry stairs:** choose **Dry stair drill**, then **Start navigation**. Move forward into an amber lane to climb from Z01 to Z02; move backward to descend. Each mercenary has a separate lane. Elevated positions support checkpoint recovery. Water and falling stay blocked; this drill does not validate the original wet staircase. See [static traversal](docs/static-traversal.md).

Opening the exact verified `Maps/Game/Map43_Training/43.map` enables the same mission flow on that local original map. Cooperative extraction is an explicit variant of its original four-player first-exit rule. Only the supported static route is in scope: optional water, the wet staircase, bridges, lifts and the button remain blocked. Dry static stairs are supported separately. This is an extraction-route prototype, not a claim of a complete faithful original level. Other editor revisions stay navigation-only.

Requires Node 22.20+ and npm. Run `npm ci`, `npm run check`, then `npm run dev` and open http://127.0.0.1:5173. `npm run build` produces a static build in dist; `npm run preview` serves it. WebGL2 is required; dependencies are bundled at build time with no remote runtime service.

The initial map is newly authored synthetic geometry. Click **Start navigation**. Four keyboard groups are shown below the views; numbers 1-4 assign WASD to a selected mercenary for fewer-player team control. Each view also allows explicit standard gamepad assignment. Press a controller button if the browser has not exposed it. D-pad/left stick moves and turns; shoulder buttons strafe. Disconnect stops that controller; matching device ID/index reconnects, otherwise reassign it. Esc, tab hiding and window focus loss pause navigation. Reset positions restarts the current map. Four physical controllers still require testing on the event PC/TV.

**Local original map:** use **Open local .map** to choose an extracted development editor file. Dropzone (`Maps/Game/Map13_Dropzone/13.map`) is the verified navigation candidate. Files stay in browser memory. Other maps can import but may fail the conservative start checks or encounter unsupported mechanics. The importer accepts only 157,738-byte raw editor files, not packed `.rnc` or runtime formats. The UI reports source hash, unknown/unsupported mechanics and current controls. Campaign travel stays disabled; original-map extraction is enabled only for the verified Training43 revision.

For a reproducible conversion/report, run `npm run import:map -- "<absolute-source.map>" --out .local/map13.json`. Existing files are never replaced. See [format details](docs/map-format.md). Do not put original data in public/; Vite's public directory is disabled.

**Recovery:** **Save checkpoint** pauses and downloads a small snapshot. To restore after a refresh, reopen the exact same map (or the same synthetic map/drill), then use **Load checkpoint**. A successful restore stays paused so you can confirm assignments. Wrong-map, oversized and invalid files leave the current state intact. Version 2 preserves positions, facing, tick, RNG, rules, countdown, retirement and outcome; original map content and controller assignments stay outside saves. Version 1 navigation checkpoints migrate explicitly. See [checkpoint format and limits](docs/checkpoints.md).

Run `npx playwright install chromium` once, then `npm run test:browser` for synthetic browser tests. To additionally smoke-test the locally held Dropzone in PowerShell, set `$env:HIRED_GUNS_MAP` to its absolute file path before running the browser tests. Simulated pads verify browser routing only, not physical controller compatibility.

Set `$env:HIRED_GUNS_TRAINING_MAP` to the absolute Training43 `.map` path to opt into its four-mercenary browser extraction proof. The test computes a supported route from local data and uses keyboard controls; no original route or map content is stored in public fixtures. Static placeholder surfaces merge coplanar faces and omit hidden block faces: locally measured Training43 block triangles fell from 83,112 to 922. This does not establish performance on the event hardware.

Original game content is not distributed here. Keep local archives and imported content in ignored `.local/` paths. Public CI uses synthetic fixtures only. Local research is outside this checkout and must not be copied wholesale into it. Format observations are source-informed; no claim of clean-room development or permission to redistribute original content is made.

See [STATUS.md](STATUS.md) for evidence, limitations and the next batch. Core contracts live in src/contracts.ts. Prototype navigation blocks opaque/solid cells, hazard cells and unsupported drops; it supports explicit dry floors, stone/stair blocks below and tree block4 two levels below. Dry directional stairs check overhead clearance and target collision. Shapes remain placeholders; gravity, water, enemies, doors, combat/inventory, sound, broader original mission state and original timing parity remain unimplemented. Stable ID order resolves contested cells; swaps into occupied-at-start cells are blocked. This is an explicit prototype policy pending reference validation.

Source countdown counters reset to 600 only after decrementing below zero, so a displayed source unit spans 601 logical ticks. The browser uses the current 50 Hz prototype clock and shows its derived time. No original executable measurement has established wall-clock parity. See [mission rules](docs/mission-rules.md) for source references and deviations.
